## Summary

## Motivation
After documenting and scripting the workflow, we must prove it works in practice so future agents clone the repo and immediately inherit the correct protections.

## Acceptance Criteria

If hook configuration causes issues, revert `.githooks/` changes and README instructions, then open a follow-up mission to adjust tooling.
