## Summary
Build a CLI tool that moves mission entries between board files, ensuring the canonical entry format (with owner, summary, group, worklog link) without manual editing.

## Motivation
Manual edits to board files are error-prone and slow. A script reduces conflicts, enforces formatting, and prepares for future automation.

## Dependencies
- `M-20251117-101`

## Deliverables
- [x] Script `bin/move-mission <mission-id> <status> --owner <handle> --summary "..."` that updates the appropriate board file and removes the entry from the previous status.
- [x] Supports statuses: `inbox`, `open`, `in_progress`, `blocked`, `review`, `done`, `archived`.
- [x] Automatically inserts `Group:` info from mission file metadata.
- [x] Documentation snippet for usage.

## Tests
- [x] Manual: move a sample mission through multiple statuses and confirm formatting remains correct.
- [x] Detect invalid status inputs and missing mission files.

## Acceptance Criteria
- Script updates board files idempotently and preserves alphabetical order by mission ID.
- Mission entries in board files follow the prescribed format, including group and worklog links.

## Rollback / Mitigation
Keep board backups before testing; if script corrupts files, rollback and fix.

## Notes
Can be implemented in bash or a Clojure script; prefer something that handles text templating reliably.
