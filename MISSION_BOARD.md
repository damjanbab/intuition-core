# Mission Board (Folder Structure)

The mission board now lives inside the `missions/` directory so we can track drafts, active work, and archives without merge wars.

- Read `missions/README.md` for the folder layout, entry format, and workflow.
- Update the appropriate file in `missions/board/` (`00_INBOX.md` … `60_ARCHIVED.md`) whenever a mission changes status.
- Store per-mission details next to the board (`missions/M-YYYYMMDD-###.md`) and keep worklogs under `worklogs/<mission-id>/WORKLOG.md`.

This stub remains only to help discover the new structure; all future edits happen inside `missions/`.
